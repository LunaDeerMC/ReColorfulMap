## 环境与方法

- Paper 26.2 build 133；Folia 26.2 build 7（官方 BETA）；Temurin Java 25.0.4.1。
- 原始 ColorfulMap 2.3 使用用户提供的 JAR，实际运行旧插件生成图片和地图物品。
- Minecraft 26.2 协议客户端通过网络执行命令、右键展示框、攻击、丢弃和拾取。辅助测试插件仅准备环境、观察状态、模拟保护插件取消事件，不直接调用生产插件的业务方法。
- 客户端累计完整及增量地图像素包，校验最终 128×128 像素与冷重启前后的 SHA-256；未进行图形客户端人工目视验收。
- 生产插件以 Java 17 构建，使用 26.2 实际服务端 API 另行核对二进制引用。

## Paper 游戏操作

最终 JAR 的主操作矩阵 **30 项全部通过**：

- 实际下载、生成 2×2 地图，以及 `0.5` 缩放。
- 四个墙面朝向 × 四个点击分块，共 16 次整幅取回并重新放置。
- 相邻框保护取消放置、保留真实玩家伤害来源的保护取消取回，均不改变手持物和墙面。
- 取回时掉落实体创建被取消，四个框中的地图恢复；背包满时留下可正常拾取的整幅地图，不删除文件。
- 缺框、混入其他图片、点击后立即切换手持槽位，均不误清邻框或消耗地图。
- 真实火焰伤害、自然消失、虚空分别产生 `DEATH`、`DESPAWN`、`OUT_OF_WORLD`，随后删除对应整幅画目录。
- 真正发生区块 `UNLOAD` 后重新加载并拾取，图片数据保持可用。
- 实际客户端收到非空白的 128×128 地图像素。

真实停服、重启后的 **6 项扩展检查全部通过**：四张墙面分块及背包缩略图恢复原路径、渲染器和完全一致的累计像素哈希；满背包且生成掉落被取消时收到失败消息、不报成功并保留图片；正常满背包生成仍能交付并收到成功消息；原版物品合并保留图片；取消自然消失保留物品和文件，之后真正消失才删除；最后创建包含 Unicode、额外 PDC 和无关原版地图的扩展迁移样本。

## 迁移失败与中断

对停服存档的独立副本运行了 10 组子进程验证：

1. 预检查不修改原文件。
2. 缺少图片时拒绝提交，存档不变。
3. 目标同名文件内容冲突时拒绝提交，存档不变。
4. 实际区块文件损坏时拒绝提交，存档不变。
5. 不支持的 LZ4 压缩在提交前拒绝，存档不变。
6. 其他进程持有世界锁时拒绝迁移；另验证了运行中的真实 Paper 世界锁。
7. 正式迁移、独立检查、重复执行、回滚，恢复原始哈希、权限和所有者。
8. 原地转换删除旧索引，回滚恢复索引及原始存档。
9. 迁移后存档被另行修改时，回滚拒绝覆盖新内容。
10. 在真正替换玩家存档后向迁移进程发送 `SIGKILL`；再次迁移拒绝未完成事务，正式 `--rollback` 恢复所有原始文件，再次迁移通过独立检查。

强杀测试使用测试专用的 `LD_PRELOAD` 重命名拦截器，生产迁移代码不包含测试故障开关。
原始 2.3 样本和扩展 Unicode 混合样本分别执行上述 10 组验证，均通过。

## 实测发现并修复的问题

- **26.2 世界身份位置变化**：实际 Paper 不再生成 `uid.dat`，世界 UUID 位于各维度 `data/paper/metadata.dat`。迁移器现读取现代元数据，支持明确指定自定义 Bukkit 世界名；身份不明或冲突时拒绝猜测，避免地图重号时关联错误图片。
- **无关 NBT 字符串**：其他插件自定义 `id` 可能包含 Java modified UTF-8 表情或 NUL。只以原始字节匹配 `minecraft:filled_map`，避免解码或改写无关数据。
- **保护事件丢失伤害来源**：实际玩家攻击复制为探测事件时，旧构造器丢失现代 DamageSource，导致依赖伤害来源的保护检查失效。现保留真实来源；真实客户端回归确认被保护墙面保持完整。
- **满背包且掉落被取消**：生成的物品无法交付时曾提示成功。现检查掉落实体状态，明确提示失败并保留图片，允许重新尝试。
- **26.2 提示消息缺失**：客户端能收到原生 `tellraw`，但收不到旧 Adventure Bukkit 适配器消息。现改用 Paper/Folia 原生 Audience；BossBar 延迟隐藏跟随玩家调度器。

## 复现和适用范围

工具及步骤见 [端到端测试说明](../tests/e2e/README.md)、[游戏操作验证](../tests/e2e/GAMEPLAY.md)、[迁移检查器](../scripts/e2e/README.md)、[Folia 冒烟测试](../tests/e2e/folia/README.md)。测试服务器只监听本机；测试辅助插件会清空测试场地和物品，只能用于隔离测试服。

本次结果证明所测真实存档在正常迁移及所测故障路径下保留了非目标数据。其他插件数据库中的虚拟背包不在扫描范围内；LZ4 和旧 oversized 区块格式会安全拒绝。Folia 验证范围为生成、消息、像素、拾取、重启和销毁，没有重复 Paper 的全部墙面与保护矩阵。

保护拦截由测试监听器在真实事件链中验证，未安装每一种第三方领地或经济插件。

运行时 PNG 文件与 Minecraft 世界保存不属于同一个事务。若服务器突然崩溃，世界可能回到此前的保存点，而已销毁物品的图片可能已经删除；不能将迁移进程的回滚保障理解为游戏运行中的整服崩溃恢复。正式升级仍应按 [存储与迁移说明](storage.md) 停服并备份世界、玩家及图片数据。
